Node.js Assignment Solutions

There are two folders:

1. file_crud
   Questions 1 to 7 covering fs, file CRUD, directories, sync/async and the notes manager.

2. server_assignment
   Questions 1 to 5 covering os, http routing, Express and middleware.

All JavaScript files use simple variable names and contain no comments.

Run the questions separately. Questions that start a server keep running until stopped with Ctrl+C.
